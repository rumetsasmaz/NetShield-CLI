# NetShield-CLI

A modular, Python-based cybersecurity command-line interface (CLI) tool designed for basic security utility, credential testing, and hands-on learning.

---

## 🚀 Features

- **Password Generator:** Generates strong, random passwords with custom parameters.
- **Port Reference:** Quick lookup utility for common network ports and services.
- **Password Strength Checker:** Analyzes password complexity, scores structural strength, and provides actionable improvement feedback.
- **Hash Generator:** Calculates cryptographic hashes (MD5 & SHA-256) for input text to analyze data integrity.
- **Hash Cracker:** Performs dictionary-based hash matching (MD5 & SHA-256) to demonstrate credential recovery and hash exposure principles.

---

## 🛠️ Stack & Technologies

- **Language:** Python 3
- **Libraries:** `hashlib`, `random`, `colorama`
