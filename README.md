# NetShield-CLI 🛡️

NetShield-CLI is a lightweight, modular command-line tool built with Python for basic cybersecurity utility and network reference tasks.

---

## 🚀 Features

- **🔐 Password Generator:** Generates strong, 12-character random passwords using uppercase letters, lowercase letters, numbers, and special symbols.
- **🔍 Port Checker:** Quick lookup database for well-known ports and their associated services/security notes.
- **🎨 Colorized Interface:** Interactive terminal experience powered by `colorama` with an ASCII banner.
